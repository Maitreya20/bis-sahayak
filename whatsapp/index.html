Formatting rules (§6.1)

  • Quick Reply buttons: max 3 per message (the language row uses a List message instead, which allows up to 10).
  • Citation line, exact format: 📄 Source: IS 302 Part 1, Clause 4.2 — ends every AI answer, no exceptions.
  • Confidence as emoji prefix: ✅ high · ⚠️ medium/partial · ❌ Not found in BIS records — here's who to contact:
  • Bold (*text*) and emoji carry hierarchy — WhatsApp has no colour, so structure does the work colour does on web/app.
  • Quick-action labels worded identically to web & app: Find my standard / Certification steps / Check hallmark / Find a lab (translated, same meaning).
  • Voice notes: user sends voice → Saaras v3 transcribes → same POST /chat → reply text + optional Bulbul v3 voice note via the 🔊 Listen button.
