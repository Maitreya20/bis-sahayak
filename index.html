The one endpoint · §3

Every surface speaks POST /chat

No surface invents its own data. Fixtures below are shaped exactly like the live contract, so the backend drops in behind one attribute.

// one attribute switches fixtures → live backend
<script src="assets/js/bis.js" data-api="https://api.bissahayak.gov.in"></script>

// POST {apiBase}/chat
{ "message": "Is IS 302 mandatory for home appliances?",
  "language": "en" }   // en | hi | mr

// 200 response
{ "answer": "IS 302 (Part 1) …",
  "citations": [{ "doc": "IS 302 Part 1", "clause": "4.2", "url": "#…" }],
  "confidence": "high",        // high | medium | low
  "suggested_actions": ["find_lab", "view_scheme", "talk_to_bis"],
  "audio_url": "#audio-demo",
  "session_id": "sess-demo" }
